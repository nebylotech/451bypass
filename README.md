# 🌐 451bypass `v1.0`

> **Умный локальный DNS для обхода блокировок без VPN и без потери скорости интернета.**

Забудьте про медленные VPN, которые тормозят весь компьютер, ломают приложения банков и мешают играть в онлайн-игры. 

**451bypass** направляет в обход только заблокированные сайты и нейросети, а весь остальной интернет работает напрямую на максимальной скорости вашего провайдера.

---

### ❓ Чем это лучше обычного VPN?

| Обычный VPN ❌ | 451bypass ⚡ |
|---|---|
| Тормозит весь интернет и режет скорость | **Скорость 100%**, интернет летает |
| Ломает банки, Госуслуги и игры | Сайты банков и игры работают напрямую |
| Постоянно отваливается и требует включения/выключения | **Работает незаметно в фоне** 24/7 |
| Платный или с рекламой | **Бесплатно навсегда** |

### 🚀 Установка за 1 минуту

1. Нажмите на клавиатуре **Пуск** и откройте **PowerShell**.
2. Вставьте эту строчку и нажмите **Enter**:

```powershell
irm https://raw.githubusercontent.com/nebylotech/451bypass/main/install.ps1 | iex
```

3. Установщик автоматически откроет браузер на странице создания бесплатного токена Cloudflare:
   * Нажмите кнопку **Create Token**
   * В первой строке выберите шаблон **Edit Cloudflare Workers** → **Use template**
   * Прокрутите страницу вниз и нажмите **Continue to summary** → **Create Token**
   * Скопируйте созданный токен и вставьте в консоль установки.

**Всё готово!** Программа сама определит ваш аккаунт, создаст личный шлюз и настроит фоновое обновление.

### 🎮 Как пользоваться?

После установки в любом терминале просто напишите:

```cmd
451b
```

Откроется простое меню управления:

```text
===============================================================
      451bypass v1.0 -- Умный обход блокировок (HTTP 451 / 403)     
===============================================================
  Обход Windows:          [ВКЛЮЧЕН (Работает)]
  Активных сайтов в базе: 477 (477 базовых, 0 своих)
  Шлюз Cloudflare:        https://ai-gateway.<your-subdomain>.workers.dev
---------------------------------------------------------------
  [1] Выключить системный обход (ON / OFF)
  [2] Проверить статус службы     - Verify Gateway, Worker, and Task health
  [3] Тест доступности сайтов     - Probe active endpoints for 451/403 bypass
  [4] Редактировать свои сайты    - Edit personal custom.txt in Notepad
  [5] Диагностика системы         - Full 8-point system diagnostics
  [6] Настроить токен Cloudflare  - Connect Cloudflare API Token
  [0] Выход
===============================================================
```

Либо управляйте командами без входа в меню:
* `451b on` — включить системный обход.
* `451b off` — выключить обход (весь интернет пойдет напрямую).
* `451b status` — проверить состояние демона, PAC и Cloudflare шлюза.
* `451b test` — протестировать доступность заблокированных эндпоинтов.

### ✏️ Как добавить свой сайт?

1. В меню выберите пункт `[4]` или введите команду `451b import`.
2. Откроется обычный **Блокнот**.
3. Добавьте нужный домен (например, `my-site.com`), сохраните и закройте.
4. **Программа умная:** она сама проверит список, уберёт случайные повторы и сразу включит обход для нового сайта.
