# 🌐 451bypass `v1.0`

> **Избирательный PAC-роутер для Windows: доступ к AI-сервисам и зарубежным API через ваш личный бесплатный Cloudflare Worker — без VPN и без потери скорости на остальных сайтах.**

Когда NVIDIA NIM, ChatGPT, Docker Hub или JetBrains возвращают ошибку **«HTTP 451 Unavailable For Legal Reasons»** — это не блокировка вашего провайдера (ТСПУ), а геоограничение на стороне самого сервиса. Обычные DPI-обходчики (GoodbyeDPI, Zapret) здесь не помогают — они не меняют ваш внешний IP.

**451bypass** решает именно эту задачу: запросы к 470+ заблокированным сервисам уходят через ваш личный Cloudflare Worker и выглядят для сервера как запросы из европейского или американского дата-центра. Весь остальной трафик (включая банки, Госуслуги, игры) идёт напрямую на полной скорости провайдера.

---

### ❓ Чем это отличается от VPN и Zapret?

| | Обычный VPN ❌ | Zapret / GoodbyeDPI ❌ | **451bypass ⚡** |
|---|---|---|---|
| Решает HTTP 451 от самих сервисов | Да, но... | **Нет** | **Да** |
| Скорость обычных сайтов | Снижается для всего трафика | Без потерь | **Без потерь** |
| Банки, Госуслуги, игры | Часто ломает | Работают | **Работают** |
| Нужен платный сервер / подписка | Да | Нет | **Нет** |
| Конфликты с античитами (Vanguard, EAC) | Да (TAP/TUN) | Да (WinDivert) | **Нет** |

> **Почему не Zapret?** Zapret десинхронизирует TCP-пакеты на оборудовании провайдера (ТСПУ). Это отлично работает для блокировок YouTube и Discord. Но когда сам NVIDIA или OpenAI видят ваш российский IP и закрывают доступ со своей стороны — DPI-обходчики бессильны. 451bypass меняет выходной IP через Cloudflare и дополняет, а не заменяет Zapret.

### 🚀 Установка за 1 минуту

1. Откройте **PowerShell** (нажмите Win → введите `powershell`).
2. Вставьте команду и нажмите Enter:

```powershell
irm https://raw.githubusercontent.com/nebylotech/451bypass/main/install.ps1 | iex
```

<details>
<summary>Хотите проверить скрипт перед запуском? (рекомендуется для осторожных)</summary>

```powershell
# Скачать скрипт для ручной проверки
Invoke-WebRequest -Uri "https://raw.githubusercontent.com/nebylotech/451bypass/main/install.ps1" -OutFile "install.ps1"
notepad install.ps1   # Откройте и изучите код
.\install.ps1         # Запустите после проверки
```

**Что делает install.ps1:**
- Скачивает файлы программы в `%LOCALAPPDATA%\451bypass`
- Регистрирует фоновую службу Windows и прописывает PAC-скрипт в настройках системы
- Открывает браузер для создания токена Cloudflare

</details>

3. Установщик откроет браузер для создания **бесплатного токена Cloudflare**:
   - Нажмите **Create Token**
   - Выберите шаблон **Edit Cloudflare Workers** → **Use template**
   - Листайте вниз → **Continue to summary** → **Create Token**
   - Скопируйте токен и вставьте в консоль.

> **Зачем нужен токен?** Чтобы воркер развернулся в *вашем* личном аккаунте Cloudflare. Ваш трафик не проходит через серверы автора — только через инфраструктуру Cloudflare. Скрипт использует исключительно права шаблона «Edit Cloudflare Workers» — без доступа к DNS, доменам или платёжным данным. Код воркера находится в [`tools/cloudflare_worker_proxy.js`](tools/cloudflare_worker_proxy.js).

**Готово!** Программа определит ваш аккаунт, создаст личный шлюз и настроит фоновую синхронизацию базы доменов.

### 🎮 Управление

После установки в любом терминале введите:

```cmd
451b
```

Откроется меню управления:

```text
===============================================================
      451bypass v1.0 -- Умный обход блокировок (HTTP 451 / 403)
===============================================================
  Обход Windows:          [ВКЛЮЧЕН (Работает)]
  Активных сайтов в базе: 477 (477 базовых, 0 своих)
  Шлюз Cloudflare:        https://ai-gateway.<your-subdomain>.workers.dev
---------------------------------------------------------------
  [1] Выключить системный обход (ON / OFF)
  [2] Проверить статус службы     - Verify Gateway, Worker, and Task health
  [3] Тест доступности сайтов     - Probe active endpoints for 451/403 bypass
  [4] Редактировать свои сайты    - Edit personal custom.txt in Notepad
  [5] Диагностика системы         - Full 8-point system diagnostics
  [6] Настроить токен Cloudflare  - Connect Cloudflare API Token
  [0] Выход
===============================================================
```

Быстрые команды без меню:
- `451b on` — включить обход
- `451b off` — выключить (весь трафик напрямую)
- `451b status` — состояние службы, PAC и Cloudflare шлюза
- `451b test` — тест доступности заблокированных эндпоинтов

### ✏️ Добавить свой сайт

1. Введите `451b` и выберите пункт `[4]`, или выполните команду `451b import`.
2. Откроется Блокнот — добавьте домен (например, `my-site.com`), сохраните и закройте.
3. Программа сама проверит список, уберёт дубли и активирует обход для нового домена.

### ⚠️ Ограничения

- **Лимит Cloudflare Workers:** 100 000 запросов в сутки на бесплатном тарифе. Для веб-серфинга и API это с запасом. Скачивание тяжёлых файлов через заблокированные сервисы будет медленнее, чем на прямом канале.
- **UDP-трафик:** PAC-файл работает только для HTTP/HTTPS. Приложения на чистом UDP обходить не умеет.
- **Cloudflare IP:** Ряд сервисов с жёсткой антибот-защитой могут блокировать диапазоны IP дата-центров Cloudflare.
